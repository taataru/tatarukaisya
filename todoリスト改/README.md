# Adventure Todo Quest

TODOをRPGのクエストとして進める、スマホ向けのブラウザ完結タスク管理アプリです。
アプリ本体は `index.html` だけで動きます。

## 機能

- 目標メモを保存
- クエストごとのEXP / Gold / 疲労度設定
- 疲労度に応じたHP減少
- HPがマイナスになった時の赤い危険表示
- テンプレートからクエスト追加
- 報酬ショップ
- localStorage保存
- JSON出力

## GitHub Pagesで公開する手順

1. このフォルダの `index.html` と `README.md` をGitHubリポジトリに入れる
2. リポジトリの `Settings` から `Pages` を開く
3. `Deploy from a branch` を選び、`main` / `/root` を指定する
4. 表示されたURLをXに貼る
