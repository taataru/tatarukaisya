# 現在地と次にやること

## できたこと

- AI自身の感情がsin波で動く
- 入力語で感情が動く
- 相手の推定感情を別状態として表示できる
- HTML/JavaScriptだけで公開会話版が動く
- `self_zone x user_zone` の16条件教材を学習できる
- Gemini候補をGemmaが既存回答と比較して取り込める
- Gemma会話を使った未知語探索の入口を作った
- 727件の自他感情教材を公開版へ反映済み

## 体感として改善した理由

以前は、相手が悲しんでいても、らいなが明るい気分なら明るい返答しか
出しにくかった。現在のブラウザ版は、らいなの気分と相手の推定気分を
組み合わせた教材から返せる。

```text
自分=楽 / 相手=哀 / 「今日は仕事で疲れた」
  -> 落ち着いたまま寄り添う返答を選べる
```

これが、語彙を増やしただけより会話が合うように感じる主な理由。

## 今の課題

| 課題 | 状態 |
| --- | --- |
| 教材数 | 727件まで増えたが、長い会話にはまだ不足 |
| 人格 | 通常寄りの教材と、重いらいな人格の方向を調整中 |
| 新規JSON | 同じ入力への別回答が多いと、語彙拡張にならない |
| Python版 | ブラウザ版と返答選択方式に差がある |
| 長い会話 | 数ターン以上の文脈理解はまだ弱い |

## 直近の育成方針

### Phase A: らいなの人格教材を増やす

- 160件単位でJSON候補を作る
- 16感情組み合わせを各10件に保つ
- 既存入力の言い換えだけでなく、新しい話題を増やす
- 重さ、嫉妬、寂しさ、怒りを自然な返答として広げる

### Phase B: 未知語探索を使う

- Gemmaに日常会話を作らせる
- 未学習の話題語を採集する
- 頻出語を使った新教材をGeminiで作る

### Phase C: Gemmaによる会話評価

語彙と基本返答が増えた後に検討する。
Gemmaが自由に会話し、らいなの実際の返答を評価して、
よい返答を出しやすくする「報酬学習風」の仕組み。

> [!todo] まだ先にする理由
> 話題が少ない段階で自由会話評価を回すと、
> らいなが知らない話題で失敗しただけなのに低評価になる。
> まず教材と話題を増やす方が効果が大きい。

## 判断メモ

- 3単語予測の強化は、いったん優先しない
- 実行時にLLMを呼ぶ方向ではなく、教師として事前に利用する
- 相手感情を持つ方向は体感改善につながっている
- 「重い人格」は欠点ではなく、らいなの設計軸として育てる
