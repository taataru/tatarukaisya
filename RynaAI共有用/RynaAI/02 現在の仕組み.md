# 現在の仕組み

## 感情空間

感情は2次元座標で持つ。

```text
        興奮 (+Y)
          |
    怒    |    喜
  --------+--------  ポジ (+X)
    哀    |    楽
          |
        落ち着き (-Y)
```

| ゾーン | 意味 |
| --- | --- |
| 喜 | ポジティブで興奮 |
| 怒 | ネガティブで興奮 |
| 哀 | ネガティブで落ち着き |
| 楽 | ポジティブで落ち着き |

## 自律的な感情波

らいなの感情は、入力がなくてもsin波で揺れる。

```text
f(t) = (15sin(t) + 7sin(t/7) + 15sin(t/30)) / 37 * 100
```

発言を受けると、単語の感情座標によって現在地点が押され、
波の上の近い位置へ乗り直す。完全なランダムではなく、
気分の流れを保ちながら言葉に反応する仕組み。

## 自分の感情と相手の推定感情

現在は二つの状態がある。

| 状態 | 内容 |
| --- | --- |
| `self_emotion` | らいな自身の現在の気分 |
| `user_emotion` | 相手の発言から推定している気分 |

相手感情は、入力に含まれる既知語の感情座標を平均し、
らいなとは別の感情波へ反映している。

> [!note]
> `user_emotion` は相手の本当の内面を知るものではなく、
> らいなが会話中に持つ「相手はいまこういう感じかも」という推定値。

## ブラウザ公開版の返答

現在の `web_chat/` は、16通りの条件から返答候補を選ぶ。

```text
ユーザー入力
  -> 相手感情を更新
  -> らいな自身の感情を更新
  -> self_zone x user_zone の教材群を選ぶ
  -> 入力に最も近い学習例の返答を返す
```

入力との近さは、単語と文字2-gramの一致で軽量に比較している。
そのため、ブラウザだけで高速に動き、Ollamaや外部APIは公開時に不要。

## Python版との違い

> [!important] 現時点の差分
> ブラウザ公開版は `self_zone x user_zone` で返答を選択する。
> 一方、`ai_core.py` の旧来のPython生成経路は、相手感情を計測・表示できるが、
> 主な文章生成は自分のゾーン別マルコフ連鎖を使う。

いま実際に体感が改善している中心は、ブラウザ版の自他感情教材選択である。

## 話題記憶

入力から最大3語をランダムに選び、5ターン保持する短期記憶がある。
記憶語を返答文に無理に差し込むのではなく、関連候補を選びやすくするために使う。
